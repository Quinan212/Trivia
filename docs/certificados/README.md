# Certificado público de Trivia

`trivia-upload-certificate.pem` es el certificado público de la clave de carga exclusiva de Trivia. Se incluye para consultar y verificar la identidad de esa clave.

SHA-256:

```text
06:09:DD:94:B9:5F:4C:06:83:71:CB:EF:F2:F6:78:EE:E0:10:F5:42:4C:B8:B1:BA:F4:76:3C:C3:49:F9:D3:4D
```

El certificado público no contiene la clave privada. Por indicación del propietario, el almacén de firma activo y su configuración también están versionados en `android/firma-google-play/` y `android/key.properties`.
